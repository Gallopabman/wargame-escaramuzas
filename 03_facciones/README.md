# Gremios y facciones

Un archivo por gremio. Plantilla de cada uno:

- Concepto (qué son, cómo luchan)
- Palabras clave y qué miniaturas encajan (cualquier miniatura que encaje en
  el oficio sirve)
- Datacards de los personajes
- Acceso a equipo, habilidades y mejoras
- Base de operaciones
- Reglas de gremio
- Subfacciones
