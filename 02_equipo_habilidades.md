# Equipo y habilidades

## Reglas especiales (apartado común)

Cualquier elemento del juego puede tener un apartado **Especial** con reglas
propias que se salen de lo normal: miniaturas, armas, armaduras, equipo,
habilidades, gremios…

- Ejemplos: *Veneno*, *Escudo* (permite bloquear disparos), *Sigilo*,
  *Volar*.

## Armas

| Estadística | Qué hace |
|---|---|
| **Atributo** | Estadística del portador que se suma a cada dado al golpear (p. ej. Fuerza o Agilidad). |
| **Daño** | Daño que hace cada impacto. |
| **Parada** | Modificador a cada dado usado para parar. |
| **Precisión** | Modificador a cada dado usado para golpear. |
| **Alcance** | Distancia máxima a la que se puede usar el arma. |
| **Velocidad** | En combate mutuo, el arma más rápida asigna sus dados primero (salvo que alguien haya cargado). |
| **Crítico** | Efecto que se activa al sacar un 6 natural. |
| **Especial** | Reglas especiales del arma (ver arriba). |

- *Parada* y *Esquiva* pueden ser negativas.
- Los disparos no se pueden bloquear salvo con armas o habilidades que lo
  indiquen (p. ej. un escudo).

## Armaduras

| Estadística | Qué hace |
|---|---|
| **Esquiva** | Modificador a cada dado usado para esquivar mientras se lleva puesta. |
| **Reducción** | Cantidad que se resta al daño de cada impacto. |
| **Durabilidad** | Número de impactos que puede reducir antes de quedar inutilizada. |
| **Especial** | Reglas especiales de la armadura (ver arriba). |
